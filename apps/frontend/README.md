# GrievanceGrid Frontend (Primary)

This app is the primary frontend for GrievanceGrid.

## Stack

- React + Vite
- TypeScript
- React Router
- TanStack Query
- Tailwind CSS

## Run

From the repository root:

```bash
npm run dev
```

From this folder directly:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Root scripts now default to this app for `dev`, `build`, and `lint`.
- The Next.js app in `apps/web` is retained as a secondary/experimental frontend.
